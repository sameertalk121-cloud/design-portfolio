# Sameer Shirgaonkar — Portfolio

A single-page design, innovation and transformation portfolio.

## Viewing

Open `index.html` in any modern browser. The page is fully self-contained: all styles, scripts and images are embedded in the one file, so there is no build step and no server required.

## Deployment (GitHub Pages)

1. Create a repository and upload `index.html` to the root (this README can sit alongside it).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Set the branch to `main` and the folder to `/ (root)`, then **Save**.
5. Wait about a minute. The site goes live at `https://<username>.github.io/<repository>/`.

To use a custom domain later (for example `sameershirgaonkar.com`), add it under **Settings → Pages → Custom domain** and point the domain's DNS at GitHub Pages.

## Notes

- The repository can be private; the published page is still reachable by anyone who has the link, so pick a non-obvious repository name if you want it kept quiet.
- Contact is via the LinkedIn link in the page footer.
